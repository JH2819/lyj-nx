LYJ  v1.0  使用说明
======================================================================

一、适用环境
----------------------------------------------------------------------
1. NX 版本：仅适配 NX 2606 / Designcenter 2606（唯一验证过的版本）
   （NX12、NX1847~NX2506 等其它版本未做适配，NX Open 接口存在差异，
     不保证可用；安装程序会在这些版本后面标 [未适配]）
2. 操作系统：Windows 7 SP1 / Windows 10 / Windows 11（64 位）
3. 运行库：.NET Framework 4.7.2 或更高
   （Windows 10 1803 以上、Windows 11 已自带，一般无需单独安装。
     若提示缺少 .NET，请安装：https://dotnet.microsoft.com/download/dotnet-framework）
4. 无需安装任何其它软件。


二、安装步骤
----------------------------------------------------------------------
1. 关闭所有正在运行的 NX 窗口。
2. 双击 "LYJ安装程序_v1.0.exe"（会请求管理员权限，必须允许，
   因为要写入 NX 安装目录下的 custom_dirs.dat）。
3. 程序会自动列出本机检测到的所有 NX 版本，勾选需要启用外挂的版本
   （只有 NX 2606 适配；其它版本后面会标 [未适配]，勾选也能装进去，但不保证可用）
4. 安装目录默认 D:\LYJ（装 D 盘，不占系统盘；没有 D 盘的机器自动改用 E/F/G，最后才回落 C 盘）。建议保持默认，纯英文路径最稳妥。
5. 点"开始安装"，几秒钟完成。
6. 重新启动 NX：
   - 菜单栏 / 顶部工具条会出现"LYJ"；
   - 功能区只有一个"LYJ"选项卡（图档导入 / 图档导出 / 加工）。


三、功能一览
----------------------------------------------------------------------
【LYJ / 图档导入】
  导入 STL（转收敛体）、导入 STP/STEP、导入 IGS、导入 X_T
【LYJ / 图档导出】
  导出 STL、导出 STP/STEP、导出 IGS、导出 X_T
【LYJ / 加工 / 加工助手】
  打开一个无模式悬浮窗，实时显示当前选中工序的刀具、转速、进给，
  可直接修改；工序的插入在悬浮窗的"模板"页里双击完成
  （安装时已把模板 prt 复制到每个 NX 的
    MACH\resource\template_part\metric，这是该功能正常工作的前提）


四、卸载
----------------------------------------------------------------------
方式一：控制面板 → 卸载程序 → LYJ → 卸载
方式二：运行 安装目录下的 "卸载LYJ.exe"

卸载会自动：从每个 NX 的 custom_dirs.dat 移除登记、移除安装时复制到
NX 加工模板目录的模板（你自己放进去的同名模板不会被删）、删除程序目录、
删除控制面板项。


五、换电脑 / 批量部署
----------------------------------------------------------------------
1. 直接把本安装包拷到目标电脑运行即可，无需拷贝原电脑的目录。
2. 静默安装（供 IT 批量部署，需管理员权限的命令行）：
      LYJ安装程序_v1.0.exe /S /DIR=D:\LYJ
   指定 NX 安装目录（一般不需要，程序会自动检测）：
      /S /DIR=D:\LYJ /NX="C:\Program Files\Siemens\DC 2606"
   生成日志：
      /S /DIR=D:\LYJ /LOG=C:\temp\install.log
3. 静默卸载：
      "D:\LYJ\卸载LYJ.exe" /U /S /DELFILES /DIR=D:\LYJ


六、常见问题
----------------------------------------------------------------------
Q1. 启动 NX 后看不到"LYJ"菜单？
    · 确认安装时勾选了对应 NX 版本（同一台机器装多个 NX 时逐个勾选）；
    · 确认 NX 完全退出后重新启动（不是点"文件→重新打开"）；
    · 检查 <NX安装目录>\UGII\menus\custom_dirs.dat 末尾是否有安装目录那一行，
      没有就重新运行安装程序点"开始安装"；
    · 若 NX 装在非默认路径且从未启动过，可能检测不到：重新启动一次 NX
      让注册表记录安装路径，再运行安装程序。

Q2. 加工助手的"模板"页是空的？
    说明加工模板没读到：确认 安装目录\config\ 下有 prt，
    且 config\cam_template.txt 指向它（一行一个路径）。改完重启 NX 即自动同步。

Q3. 装在别的 NX 版本上，点"导入STL"提示不支持？
    本外挂只适配 NX 2606。其它版本上出现这类提示属正常现象：
    收敛体 STL 导入接口只在较新版本才有，请改用 NX 自带
    "文件 → 导入 → STL"，或改用 导入STP / 导入X_T。

Q4. 想换成自己的加工模板？
    把模板 prt 放进 安装目录\config\，然后编辑
    安装目录\config\cam_template.txt，写入模板的完整路径（一行一个，
    取第一个存在的），重启 NX 后自动同步。
    注意：模板名就是 prt 的文件名；加工助手里插入工序时，该 prt 必须存在于
    每个 NX 的 MACH\resource\template_part\metric 下——重新运行一次安装程序
    会自动帮你复制过去（安装时会把 config\ 下的 prt 全部装进 NX 模板目录）。

Q5. 图标显示空白？
    图标由程序运行时生成，需要安装目录有写权限。安装时已自动授权
    Users 修改权限；若被安全软件拦截，可手动给安装目录加写权限后
    重启 NX 重新生成。


七、安装目录结构（了解即可，勿随意删除）
----------------------------------------------------------------------
  安装包里只带下面带"★"的文件，其余全部由程序在第一次启动 NX 时自动生成：

  D:\LYJ\
    startup\        NX 启动时读取的菜单 / 功能区 / DLL
      lyj.men                 ★ 主菜单
      rbn_lyj.rtb             ★ "LYJ"选项卡（图档导入 / 图档导出 / 加工）
      rbn_lyj_import.grb      ★ 图档导入组
      rbn_lyj_export.grb      ★ 图档导出组
      rbn_lyj_cam.grb         ★ 加工组（加工助手按钮）
      LYJ.dll                 ★ 外挂主程序
    application\    功能区 / 菜单图标（bmp）
      lyj_*.bmp               ★ 功能区 / 菜单按钮图标 9 张
      cam_op_*.bmp / cam_grp_*.bmp  工序 / 文件夹图标（自动生成）
    config\         加工模板与配置
      测试.prt                    ★ 加工模板（安装时自动复制到各 NX 的模板目录）
      cam_template.txt              当前使用的模板路径（自动生成，可手工改）
      cam_strategies.txt            工序清单（自动生成）
      cam_strategies.stamp          模板时间戳（自动生成，决定要不要重新同步）
      icon_map.txt                  图标记录（自动生成，只补缺不重画）
      BMP\                          自定义工序图标素材（自动建目录，可空）

  也就是说：startup 里就是上面这几个带"★"的文件，其余的配置、图标
  由程序在启动 NX 时自动补齐（改过模板后重启一次即同步）。


技术支持：把安装日志（加 /LOG 参数生成）和 NX 版本号一并发回即可定位问题。
