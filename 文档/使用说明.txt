LYJ  v1.1  使用说明
======================================================================

一、适用环境
----------------------------------------------------------------------
1. NX 版本：仅适配 NX 2606 / Designcenter 2606（唯一验证过的版本）
   （NX12、NX1847~NX2506 等其它版本未做适配，NX Open 接口存在差异，
     不保证可用；安装程序会在这些版本后面标 [未适配]）
2. 操作系统：Windows 7 SP1 / Windows 10 / Windows 11（64 位）
3. 运行库：.NET Framework 4.7.2 或更高
   （Windows 10 1803 以上、Windows 11 已自带，一般无需单独安装。
     若提示缺少 .NET，请安装：https://dotnet.microsoft.com/download/dotnet-framework）
4. 无需安装任何其它软件。


二、安装步骤
----------------------------------------------------------------------
1. 关闭所有正在运行的 NX 窗口。
2. 双击 "LYJ安装程序_v1.1.exe"（会请求管理员权限，必须允许，
   因为要写入 NX 安装目录下的 custom_dirs.dat）。
3. 程序会自动列出本机检测到的所有 NX 版本，勾选需要启用外挂的版本
   （只有 NX 2606 适配；其它版本后面会标 [未适配]，勾选也能装进去，但不保证可用）
4. 安装目录默认 D:\LYJ（装 D 盘，不占系统盘；没有 D 盘的机器自动改用 E/F/G，最后才回落 C 盘）。建议保持默认，纯英文路径最稳妥。
5. 点"开始安装"，几秒钟完成。
6. 重新启动 NX：
   - 菜单栏 / 顶部工具条会出现"LYJ"；
   - 功能区只有一个"LYJ"选项卡
     （图档导入 / 图档导出 / 显示 / 加工）。


三、功能一览
----------------------------------------------------------------------
【LYJ / 导入图档】
  只有一个按钮：选完文件后按扩展名自动匹配导入器，不用先挑格式。
  覆盖 NX 原生"文件 → 导入"里的全部图档格式：

  · 实体 / 曲面 CAD
    .prt                    NX 部件（按文件头判别；Creo 部件自动走 Creo 导入器）
    .stp / .step            STEP，读文件头自动识别 AP203 / AP214 / AP242
    .igs / .iges            IGES，按 NURBS 样条重建曲面与曲线
    .x_t / .x_b             Parasolid
    .xmt_txt / .xmt_bin     Parasolid（文本 / 二进制）
    .CATPart / .CATProduct  CATIA V5
    .model / .exp / .session / .dlv
                            CATIA V4
    .3dxml                  CATIA V6（3DXML）
    .prt / .asm / .xpr / .xas / .neu
                            Creo / Pro-E（.prt.1 这类版本号后缀也能识别）
    .ipt / .iam             Autodesk Inventor
    .3dm                    Rhino
    .sat / .sab / .asat     ACIS（自动勾选缝合）
    .dxf / .dwg             DXF / DWG
    .g3d                    G3D
    .mf1 / .arc / .unv / .pkg
                            I-deas
  · 网格 / 面片
    .stl                    STL（导入为小平面体并转收敛体，自动放到第 1 层）
    .3mf                    3MF
    .obj                    Wavefront OBJ
    .wrl / .vrml            VRML
  · 建筑 / 二维 / 其他
    .ifc                    IFC（自动勾选展平装配）
    .rvt                    Revit
    .asc                    ASC
    .shp                    Geospatial 地理数据
    .cgm                    CGM

  展平装配 / 缝合：导入器带这两个选项的一律勾选
  （STEP、IGES、Parasolid、IFC 勾展平装配；STEP、IGES、ACIS 勾缝合），
  其余参数保持 NX 默认值。
  块、符号、点云（POINTS）等非图档对象没有编程接口，请用 NX 自带导入。
【LYJ / 图档导出】
  功能区里是一个「导出图档」下拉按钮，点开（或点右下角箭头）展开四项：
    导出 STL、导出 STP/STEP、导出 IGS、导出 X_T
  菜单栏 LYJ → 图档导出 里是同样这四项。
  导出前先框选要导出的体，格式自己指定（与 NX 原生导出一致）。
【LYJ / 显示】
  功能区"显示"组里固定 12 个只有图标的中号按钮（48x48 色块，没有文字）：
    透明化 / 颜色1 ... 颜色10 / 配置
  没配置的槽画成"＋"空位（点它直接打开配置窗口）；
  鼠标停在按钮上会显示这个按钮的颜色名。
  ---- 透明化 ----
  点"透明化"弹出 NX 原生对话框：
    上半区  选择对象（可多选；打开时自动带入图形区里已经选中的对象）
            图形区里直接点实体或片体即可（鼠标一放上去高亮的整个体），
            也可以在部件导航器里选"体"或生成它的特征（如 块(1)）
    下半区  透明度滑条 0~100（整数级，不显示小数）
  拖动滑条或增删部件都是立即生效的，不用点确定也能看到效果；
  点"确定"保留效果，点"取消"回到打开对话框前的样子。
  只改显示属性（相当于 NX 的"编辑对象显示"），不动几何。
  ---- 颜色按钮 ----
  出厂默认五颗：
    淡蓝(137,182,255) / 浅绿(215,255,199) / 浅灰(153,153,153)
    / 白色(255,255,255) / 黑色(0,0,0)
  点颜色按钮的流程：先定"改哪些对象"，再预览，最后确认。
    · 图形区里已经选好对象 → 直接用，不再问
    · 没选 → 弹出 NX 原生的"类选择"对话框：类型清单里有 实体 / 片体 / 面 /
      基准平面 / 坐标系 / 点，默认只勾"实体 + 片体"（点模型任意一处都是
      整个体改色）；想只改一个面，就只勾"面"再点那个面
    · 选完点"确定"，颜色立刻显示出来（不用再点别的），随后弹出一个小面板：
      点"确定"保留（之后可以按 Ctrl+Z 一步撤销这次改色），
      点"取消"恢复改之前的颜色
    · 点到实体 / 片体 = 整个体连同它所有面一起变色（NX 里单独设过颜色的面
      不跟随体色，不这么做就会出现"整体改了色、某个面还是旧颜色"）
    · 预览不会被橙色"选中高亮"盖住：预览期间 NX 的选择色临时跟着目标色走，
      看到的就是真实颜色；面板关掉自动还原
  改色时按 调色板编号 → 调色板名 → 色值（容差 2%）三级找，
  都对不上会提示去配置里换一个颜色，不会瞎套一个错颜色。
  ---- 配置（组尾那颗九宫格按钮） ----
  点开是 NX 原生对话框，10 个颜色槽：
    · 每个槽 = 一个启用勾选 + 一个颜色块
    · 点颜色块弹出的是 NX 内置调色板，选哪个就是哪个色号
    · 前 5 个槽默认就是上面五个颜色，6~10 号默认空着，
      勾上并选个颜色就能用（最多 10 个颜色）
  点"确定"后保存到 config\color_slots.txt，并重画图标。
  **改颜色不需要重启 NX**：颜色值是点按钮时现场读配置的，
  保存后回到图形区直接点就是新颜色。
  只是按钮上那颗小色块的"图示"是启动时加载的图，
  颜色要到下次启动 NX 才刷新（配置窗口里也会这样提示）。
  图标文件名带配置指纹，配置一变就换一组新文件名，
  不会出现"重启后仍显示旧颜色"的情况。
  配置文件是纯文本，也可以用记事本直接改：
    序号 <TAB> 启用(1/0) <TAB> 色号(0=按名字/色值) <TAB> R <TAB> G <TAB> B <TAB> 备注 <TAB> 调色板名
  菜单栏 LYJ → 部件颜色（子菜单）/ 配置颜色按钮 里是同样这些入口。
【LYJ / 加工 / 加工助手】
  打开一个无模式悬浮窗，实时显示当前选中工序的刀具、转速、进给，
  可直接修改；工序的插入在悬浮窗的"模板"页里双击完成
  （安装时已把模板 prt 复制到每个 NX 的
    MACH\resource\template_part\metric，这是该功能正常工作的前提）
  "模板"页背景是浅灰色半透明（约 55%），文字/树线压在上面，既能看清策略又能透出背后的模型；
  "加工参数"页仍是全透明，只留文字。
  点标题栏左侧的齿轮可配置：字体、字号、是否加粗（细笔画字体如仿宋建议勾上）、
  显示哪些参数行、行的上下顺序与颜色。配置存在 %APPDATA%\LYJ\mach_assistant.cfg。


四、卸载
----------------------------------------------------------------------
方式一：控制面板 → 卸载程序 → LYJ → 卸载
方式二：运行 安装目录下的 "卸载LYJ.exe"

卸载会自动：从每个 NX 的 custom_dirs.dat 移除登记、移除安装时复制到
NX 加工模板目录的模板（你自己放进去的同名模板不会被删）、删除程序目录、
删除控制面板项。


五、换电脑 / 批量部署
----------------------------------------------------------------------
1. 直接把本安装包拷到目标电脑运行即可，无需拷贝原电脑的目录。
2. 静默安装（供 IT 批量部署，需管理员权限的命令行）：
      LYJ安装程序_v1.1.exe /S /DIR=D:\LYJ
   指定 NX 安装目录（一般不需要，程序会自动检测）：
      /S /DIR=D:\LYJ /NX="C:\Program Files\Siemens\DC 2606"
   生成日志：
      /S /DIR=D:\LYJ /LOG=C:\temp\install.log
3. 静默卸载：
      "D:\LYJ\卸载LYJ.exe" /U /S /DELFILES /DIR=D:\LYJ


六、常见问题
----------------------------------------------------------------------
Q1. 启动 NX 后看不到"LYJ"菜单？
    · 确认安装时勾选了对应 NX 版本（同一台机器装多个 NX 时逐个勾选）；
    · 确认 NX 完全退出后重新启动（不是点"文件→重新打开"）；
    · 检查 <NX安装目录>\UGII\menus\custom_dirs.dat 末尾是否有安装目录那一行，
      没有就重新运行安装程序点"开始安装"；
    · 若 NX 装在非默认路径且从未启动过，可能检测不到：重新启动一次 NX
      让注册表记录安装路径，再运行安装程序。

Q2. 加工助手的"模板"页是空的？
    说明加工模板没读到：确认 安装目录\config\ 下有 prt，
    且 config\cam_template.txt 指向它（一行一个路径）。改完重启 NX 即自动同步。

Q3. 导入时提示"不支持该功能"或"不支持的文件类型"？
    · "不支持该功能"：本外挂只适配 NX 2606，其它版本缺少收敛体 STL 等
      接口，属正常现象，请改用 NX 自带的"文件 → 导入 → 对应格式"。
    · "不支持的文件类型"：导入按扩展名识别，NX 原生导入的图档格式都覆盖
      （STEP / IGES / Parasolid / CATIA / Creo / DXF / ACIS / Rhino /
      Inventor / STL / 3MF / OBJ / VRML / IFC / Revit / 3DXML / G3D /
      I-deas / ASC / Geospatial / CGM 等）；扩展名被改过（如 xxx.stp.txt）
      就识别不出来，改回正确扩展名即可。

Q4. 想换成自己的加工模板？
    把模板 prt 放进 安装目录\config\，然后编辑
    安装目录\config\cam_template.txt，写入模板的完整路径（一行一个，
    取第一个存在的），重启 NX 后自动同步。
    注意：模板名就是 prt 的文件名；加工助手里插入工序时，该 prt 必须存在于
    每个 NX 的 MACH\resource\template_part\metric 下——重新运行一次安装程序
    会自动帮你复制过去（安装时会把 config\ 下的 prt 全部装进 NX 模板目录）。

Q5. 图标显示空白？
    图标由程序运行时生成，需要安装目录有写权限。安装时已自动授权
    Users 修改权限；若被安全软件拦截，可手动给安装目录加写权限后
    重启 NX 重新生成。


七、安装目录结构（了解即可，勿随意删除）
----------------------------------------------------------------------
  安装包里只带下面带"★"的文件，其余全部由程序在第一次启动 NX 时自动生成：

  D:\LYJ\
    startup\        NX 启动时读取的菜单 / 功能区 / DLL
      lyj.men                 ★ 主菜单
      rbn_lyj.rtb             ★ "LYJ"选项卡（导入 / 导出 / 显示 / 加工）
      rbn_lyj_import.grb      ★ 图档导入组
      rbn_lyj_export.grb      ★ 图档导出组
      rbn_lyj_color.grb       ★ 显示组（固定 12 个按钮：透明化 + 颜色1~10 + 配置）
      rbn_lyj_cam.grb         ★ 加工组（加工助手按钮）
      LYJ.dll                 ★ 外挂主程序
    application\    功能区 / 菜单图标（bmp）与 NX 原生对话框定义
      lyj_*.bmp               ★ 功能区 / 菜单按钮图标 19 张
                                （显示组的是 48x48 中号色块，程序启动时按配置重画；
                                 没配置的槽画成"＋"空位）
      LYJ_Transparency.dlx    ★ 透明化对话框（NX Block Styler 定义）
      LYJ_ColorPick.dlx       ★ 改颜色选择对话框（先点颜色按钮再选对象）
      LYJ_ColorConfig.dlx     ★ 显示组配置对话框（NX 内置色盘）
      cam_op_*.bmp / cam_grp_*.bmp  工序 / 文件夹图标（自动生成）
    config\         加工模板与配置
      测试.prt                    ★ 加工模板（安装时自动复制到各 NX 的模板目录）
      cam_template.txt              当前使用的模板路径（自动生成，可手工改）
      cam_strategies.txt            工序清单（自动生成）
      cam_strategies.stamp          模板时间戳（自动生成，决定要不要重新同步）
      icon_map.txt                  图标记录（自动生成，只补缺不重画）
      color_slots.txt               显示组每个颜色按钮的色号/开关（首次启动生成，可直接编辑）
      BMP\                          自定义工序图标素材（自动建目录，可空）

  也就是说：startup 里就是上面这几个带"★"的文件，其余的配置、图标
  由程序在启动 NX 时自动补齐（改过模板后重启一次即同步）。


技术支持：把安装日志（加 /LOG 参数生成）和 NX 版本号一并发回即可定位问题。
